用例清单（每条对应一个真实行为，不做无意义断言）：

**`tst_blobstore.cpp`（Catch2）**
- `saveImage`/`saveThumbnail` 产出 `<dir>/<hash>.png`、`<dir>/<hash>.thumb.png`
- `remove(hash)` 同时删主图与缩略图，其他文件不受影响
- `clear()` 清空目录但保留目录本身；`initialize()` 在空目录参数下返回 false

**`tst_store.cpp`（Catch2，每个用例用 `QTemporaryDir`，Store 作用域内创建/销毁）**
- `open()` 后 `PRAGMA user_version == 3`
- v1 库迁移：用命名连接手工建 v1 表 + `user_version=1` + 一条文本行，关闭后再 `Store::open`，旧行仍可读且 `kind == text`（验证 `migrate()` 的 `version < 1/2/3` 分支）
- `addItem` 同 hash 二次写入：`count() == 1`，`createdAt` 被更新（唯一索引 + upsert）
- `search("hell")` 命中 `hello world`（FTS5 前缀），`search("") == recent()`
- `removeEntry` 删除图片行时对应 blob 文件消失
- `clearAll` 清空 entries 与 blobs 目录
- 插入 1005 条后 `count() == 1000`，且保留的是最新的 1000 条（`prune()`）

**`tst_capture_service.cpp`（QtTest，`QTEST_MAIN`）**
- 纯空白文本 → 不发 `ready`（`QTest::qWait(200)` 后 `QSignalSpy` 为空）
- 正常文本 → `ready` 携带非空 hash 与 `byteSize`
- Files → `text` 为换行连接的路径，空路径项被过滤
- `QImage(10,10,Format_RGB32)` 转 PNG 字节提交 → `path`/`thumbPath` 文件存在、`width/height == 10`

**`tst_history_window.cpp`（QtTest）**
- 预置 3 条文本（直接构造 `PreparedItem` 调 `store.addItem`）→ `refresh()` 后 `QListWidget::count() == 3`
- 搜索框输入关键词 → 列表项减少（通过 `findChild<QLineEdit*>` 设置文本触发 `textChanged`）
- `QTest::keyClick(search, Qt::Key_Delete)` → 当前行被删且 `store.count()` 减 1
- `QTest::keyClick(search, Qt::Key_Return)` → 发出 `entryActivated(id)`
- `show()` 后 `Qt::Key_Escape` → `isHidden() == true`

**`tst_autostart.cpp`（QtTest）**
- `setEnabled(true)` → 用户目录出现 `autostart/clipman.desktop` 且 `Hidden=false`（`QSettings` 读回校验）
- `setEnabled(false)` → 同文件 `Hidden=true`，`isEnabled() == false`
- 无用户文件、无系统文件 → `isEnabled() == false`（构造时注入临时用户目录与不存在的系统路径，避免受本机环境影响）

### 3.4 `src/platform/Autostart.h` / `.cpp`（新增）

```cpp
// 读写用户级 ~/.config/autostart/clipman.desktop，用来覆盖 /etc/xdg/autostart 的系统项。
// 只依赖 QtCore；构造参数供测试注入目录。
class Autostart
{
public:
    explicit Autostart(QString userDir = {}, QString systemFile = QString());

    bool isEnabled() const;
    bool setEnabled(bool enabled, QString *error = nullptr);

private:
    bool userHidden() const;   // 用户文件存在时读 [Desktop Entry]/Hidden
    QString m_userFile;
    QString m_systemFile;
};
```

- 默认值：`m_userFile = QStandardPaths::writableLocation(ConfigLocation) + "/autostart/clipman.desktop"`；`m_systemFile = "/etc/xdg/autostart/clipman.desktop"`
- `isEnabled()`：用户文件存在 → `!Hidden`；否则系统文件存在 → true；都没有 → false
- `setEnabled()`：`QDir().mkpath` 父目录后用 `QSaveFile` 写整份 desktop 文件（启用时 `Hidden=false`，禁用时 `Hidden=true`），内容与 `packaging/clipman-autostart.desktop` 一致，`Exec=clipman`、`Icon=clipman`
- 失败返回 false 并写 `error`，由调用方 `qWarning`

## 4. 假设与决策

| 项 | 决策 | 理由 |
| --- | --- | --- |
| 打包方式 | CPack `DEB` + `dpkg-deb`，不用 `dpkg-buildpackage` | 本机 sudo 禁用、无 debhelper；CPack 可立即产出并校验真实 deb |
| AppImage | 不做 | 用户决策；且需联网下载 linuxdeploy |
| 自启策略 | 系统级 `/etc/xdg/autostart` 默认自启 + 托盘「开机自启」写用户级 `~/.config/autostart` 覆盖（`Hidden=true` 屏蔽） | XDG 标准机制，deb 无法直接写用户 home |
| deb 可移植性 | 去掉 RUNPATH；依赖声明用 noble 的 t64 包名 | 避免包里带 `/home/louis/Qt/...` 路径；Qt 6.8 vs 6.4 的 ABI 限制写入风险表 |
| 测试框架分工 | 同步 core 用 Catch2，异步 `CaptureService` 与 UI/Autostart 用 QtTest | CaptureService 依赖事件循环与信号，QtTest 的 `QTRY_*` 比在 Catch2 里手搓 `QEventLoop` 简单 |
| Store 测试隔离 | 每个用例作用域内构造/析构 `Store`，用 `QTemporaryDir` | `QSqlDatabase` 用默认连接名，不能并存两个 Store；不为此改动产品接口 |
| 测试源文件归属 | 测试目标直接编译 `HistoryWindow.cpp`、`Autostart.cpp` | 不新增 `clipman_ui` 库，避免为测试重构产品结构 |
| clang-tidy | 只提供配置，不接入默认构建 | 全量 tidy 会显著拖慢编译；"零警告"指编译器警告 |
| CI / 提交 | 不新增 CI 配置文件；不自动 git commit | 本任务只做工程化文件与验证，提交由用户决定 |
