## 1. 摘要

M1 在现有最小闭环（XFixes 监听 + SQLite + 托盘）上补齐 6 项：

1. X11 全局快捷键 `Ctrl+Alt+V` 唤起/隐藏面板（确认：不实现 portal，延后到 M4）
2. 面板改造为弹出式搜索面板，支持 ↑/↓、Enter、Esc、失焦隐藏
3. 单击列表项即复制
4. FTS5 全文检索（迁移到 v2），`Store::search()`
5. 单条删除（Delete 键 + 右键菜单）
6. 修复 `XcbClipboardWatcher::suppressNext()` 空实现与 `m_owner` 不同步

不改 `Entry` 结构，不引入新系统依赖，不引入 Qt6::DBus。

## 3. 变更明细

### 3.1 `src/core/Store.h` / `Store.cpp`：FTS5 与删除

**Store.h 新增：**

```cpp
QVector<Entry> search(const QString &query, int limit = 200) const;
bool removeEntry(qint64 id, QString *error = nullptr);
```

**迁移版本升到 2。** 把 `migrate()` 改成按版本递进（单个事务内）：

- `version < 1`：保留现有 `entries` 表与 `idx_entries_created_at` 创建语句。
- `version < 2`：创建 FTS5 外部内容表与同步触发器，并重建索引：

```sql
CREATE VIRTUAL TABLE IF NOT EXISTS entries_fts USING fts5(
  text_content, content='entries', content_rowid='id', tokenize='unicode61'
);
CREATE TRIGGER IF NOT EXISTS entries_ai AFTER INSERT ON entries BEGIN
  INSERT INTO entries_fts(rowid, text_content) VALUES (new.id, new.text_content);
END;
CREATE TRIGGER IF NOT EXISTS entries_ad AFTER DELETE ON entries BEGIN
  INSERT INTO entries_fts(entries_fts, rowid, text_content)
  VALUES ('delete', old.id, old.text_content);
END;
CREATE TRIGGER IF NOT EXISTS entries_au AFTER UPDATE ON entries BEGIN
  INSERT INTO entries_fts(entries_fts, rowid, text_content)
  VALUES ('delete', old.id, old.text_content);
  INSERT INTO entries_fts(rowid, text_content) VALUES (new.id, new.text_content);
END;
INSERT INTO entries_fts(entries_fts) VALUES ('rebuild');
```

- 语句末尾 `PRAGMA user_version = 2`。整个迁移失败则回滚并返回错误（保持现有行为）。
- 注意：`addText()` 的 `ON CONFLICT(hash) DO UPDATE` 会触发 `entries_au`，FTS 自动同步；`prune()`/`clearAll()` 的 DELETE 触发 `entries_ad`，无需额外代码。

**`search()` 实现：**

- `query.trimmed()` 为空 → 直接返回 `recent(limit)`。
- 构造 FTS 查询：按空白分词，每个词双引号包裹并把内部 `"` 转义为 `""`，词尾加 `*` 做前缀匹配，多词以空格连接（隐式 AND）。若所有词都被过滤为空 → `recent(limit)`。
- 执行：

```sql
SELECT e.id, e.hash, e.text_content, e.created_at
FROM entries_fts f JOIN entries e ON e.id = f.rowid
WHERE entries_fts MATCH ?
ORDER BY rank
LIMIT ?
```

- `exec()` 失败（如用户输入触发 FTS 语法错误）时 `qWarning` 并回退 `recent(limit)`，不把异常抛给 UI。

**`removeEntry()`：** `DELETE FROM entries WHERE id = ?`，失败时写 `error`。

### 3.2 新增 `src/platform/X11Hotkey.h` / `X11Hotkey.cpp`：X11 全局快捷键

接口（与 `XcbClipboardWatcher::create()` 风格一致）：

```cpp
class X11Hotkey : public QObject, public QAbstractNativeEventFilter
{
    Q_OBJECT
public:
    static std::unique_ptr<X11Hotkey> create(QObject *parent = nullptr);
    ~X11Hotkey() override;
    bool isActive() const;
    bool nativeEventFilter(const QByteArray &eventType, void *message, qintptr *result) override;
signals:
    void activated();
private:
    explicit X11Hotkey(xcb_connection_t *connection, QObject *parent);
    bool initialize();
    xcb_connection_t *m_conn = nullptr;
    xcb_window_t m_window = XCB_NONE;
    xcb_keycode_t m_keycode = 0;
    QVector<quint16> m_modifiers;
    bool m_active = false;
    bool m_filterInstalled = false;
};
```

实现要点：

- `create()`：通过 `qApp->nativeInterface<QNativeInterface::QX11Application>()` 取 xcb 连接；拿不到返回 `nullptr`（由 main 打印警告，程序其余功能照常）。
- 创建 1×1 `XCB_WINDOW_CLASS_INPUT_ONLY` 窗口接收按键事件。
- 键码解析：用 `xcb_get_keyboard_mapping` 遍历键盘映射，查找 keysym `0x76`（`XK_v`，对应 V 键）；找不到返回 `false`。
- 修饰键组合：`Ctrl(XCB_MOD_MASK_CONTROL) | Alt(XCB_MOD_MASK_1)`，并额外覆盖 `CapsLock(XCB_MOD_MASK_LOCK)` 与 `NumLock(Mod2=16)` 四种组合。
- 用 `xcb_grab_key_checked()` + `xcb_request_check()` 检测 `BadAccess`（快捷键被占用）；至少一个组合成功即视为激活，全部失败返回 `false` 并 `qWarning`。
- `nativeEventFilter`：`eventType == "xcb_generic_event_t"`，响应 `XCB_KEY_PRESS`，`detail == m_keycode` 且 `state` 含 Ctrl+Alt 时 `emit activated()` 并返回 `true` 吞掉事件。
- 析构：`xcb_ungrab_key` 所有组合、销毁窗口、移除事件过滤器。

> 快捷键常量 `Ctrl+Alt+V` 固定在 `X11Hotkey` 内部；M1 不做设置界面（M4）。

### 3.3 `src/ui/HistoryWindow.h` / `HistoryWindow.cpp`：弹出式搜索面板

**头文件新增：**

```cpp
class QLineEdit;
// ...
public:
    void showPanel();
    void togglePanel();
protected:
    bool eventFilter(QObject *watched, QEvent *event) override;
    void keyPressEvent(QKeyEvent *event) override;
private:
    void activateCurrent();
    void deleteCurrent();
    QLineEdit *m_search = nullptr;
```

**构造与外观：**

- `setWindowFlags(Qt::Popup);`（无边框、点击外部自动关闭、键盘 grab 保证搜索框拿到焦点）；`resize(520, 480)`。
- 布局自上而下：`QLineEdit m_search`（占位符「搜索剪贴板历史…」）→ `QListWidget m_list` → 底部行（`m_summary` + 现有「清空」按钮）。
- 列表保持 `SingleSelection / NoEditTriggers / ElideRight`。

**刷新（`refresh()` 改造）：**

- 查询改为 `m_store.search(m_search->text())`（空串自然回退 `recent()`）。
- 每项：显示 `MM-dd HH:mm:ss + simplified 文本`；`Qt::UserRole` 存原文，`Qt::UserRole + 1` 存 `entry.id`；tooltip 保留。
- 写完 `setCurrentRow(0)`；`m_summary` 显示「共 N 条」+ 操作提示「↑↓ 选择 · Enter 复制 · Delete 删除 · Esc 关闭」。
- `m_search` 的 `textChanged` 直接连接 `refresh()`（输入即搜）。

**交互：**

- `itemClicked`（单击）与 `itemActivated`（双击/回车）都调用 `activateCurrent()`：取当前项原文 → `emit entryActivated(text)` → `hide()`。
- 在 `m_search` 和 `m_list` 上安装 `eventFilter`，统一处理按键（保证焦点可一直留在搜索框）：
  - `Key_Up` / `Key_Down`：移动 `currentRow`，返回 `true`
  - `Key_Return` / `Key_Enter`：`activateCurrent()`，返回 `true`
  - `Key_Escape`：`hide()`，返回 `true`
  - `Key_Delete`：`deleteCurrent()`，返回 `true`
- `deleteCurrent()`：取 `Qt::UserRole + 1` 的 id → `m_store.removeEntry(id)` → `refresh()`（刷新后选中第一项）。
- 列表 `setContextMenuPolicy(Qt::CustomContextMenu)`，右键菜单含「复制」「删除」两项，分别对应 `activateCurrent()` / `deleteCurrent()`。
- `keyPressEvent`：`Esc` → `hide()`，其余交给基类。
- `event(QEvent::WindowDeactivate)` 时 `hide()` 作为失焦兜底。

**`showPanel()`：**

1. `m_search->clear()`（触发一次 refresh）
2. `refresh()`
3. 定位：取 `QCursor::pos()` 所在屏幕的 `availableGeometry()`，面板以光标上方居中放置，并 `qBound` 到屏幕内
4. `show(); raise(); activateWindow(); m_search->setFocus();`

**`togglePanel()`：** `isVisible() ? hide() : showPanel()`。

### 3.6 `src/platform/XcbClipboardWatcher.cpp`：修复 suppressNext / m_owner

- `suppressNext(const QString &text)` 改为记录 `m_lastText = text;`，使回填产生的 selection 回响即使进入 `finishTransfer()` 也会因 `text == m_lastText` 被跳过。
- `handleXfixesEvent()` 中把 owner 记账移动到 `ownsClipboard()` 判断之前：

```cpp
m_owner = event->owner;
m_ownerTime = event->timestamp;

if (QGuiApplication::clipboard()->ownsClipboard())
    return;
```

  这样自身取权后 `m_owner` 与真实 owner 一致，后续重复 XFixes 事件能被现有去重条件正确过滤。

## 4. 假设与决策

| 项 | 决策 |
| --- | --- |
| 快捷键后端 | 仅 X11 `grab_key`；不做 xdg-desktop-portal（确认延后到 M4） |
| 默认快捷键 | 固定 `Ctrl+Alt+V`，不可配置（M4 设置界面再做） |
| 面板窗口类型 | `Qt::Popup`，保证唤起后键盘焦点在搜索框，点击外部自动隐藏 |
| 搜索语义 | FTS5 `unicode61` + 前缀匹配；中文按整段 token 处理，从词首输入可命中，不做 trigram |
| 空查询 | 回退到 `recent()`，与现有行为一致 |
| 删除范围 | 单条删除；清空仍走托盘/面板清空按钮 |
| 测试 | M1 不新增自动化测试（M3 引入 Catch2/QtTest），用第 5 节手工验收 |
| schema | 只新增 FTS5 表与触发器，`entries` 表结构不动，迁移 v1 → v2 可直接升级旧库 |

**手工验收（对齐 PLAN 的 M1 验收）：**
